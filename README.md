# Page2Page — Платформа студенческого буккроссинга

**Page2Page** — это веб-платформа для студенческого обмена литературой (включая мангу и учебные материалы), которая позволяет участникам каталогизировать прочитанные книги, обмениваться ими внутри сообщества, оставлять отзывы и управлять статусами бронирования. Проект разработан с использованием **Node.js** на бэкенде.

---

## 🚀 Функционал и возможности проекта

* **CRUD-операции с объявлениями:** Добавление, редактирование, удаление книг/манги и изменение их статуса (*доступна, забронирована, отдана*).
* **Загрузка медиафайлов:** Загрузка и хранение изображений обложек книг.
* **Серверный поиск и фильтрация:** Поиск литературы по названию, автору, а также фильтрация по жанрам и статусу на стороне сервера.
* **Система отзывов и бронирования:** Возможность бронировать понравившиеся издания и оставлять рецензии.
* **Разграничение прав доступа:** Многоуровневая ролевая модель для обеспечения безопасности и порядка.

---

## 👥 Ролевая модель пользователей

### 1. Администратор (Admin)
* **Назначение:** Полный технический и административный контроль над платформой, базой данных Node.js и учетными записями.
* **Права:**
  * Управление всеми пользователями (блокировка, смена ролей, удаление аккаунтов).
  * Полный доступ к управлению всем контентом и системными каталогами (жанры, категории).
  * Настройка серверной логики и модерирование всей базы объявлений и отзывов.
* **Уровень системы:** Суперпользователь (полный доступ к бэкенду, базе данных и REST API маршрутам).

### 2. Модератор (Moderator)
* **Назначение:** Контроль за качеством контента, проверка корректности объявлений о книгах и отзывов.
* **Права:**
  * Просмотр, редактирование или удаление объявлений и отзывов, нарушающих правила платформы (например, спам или запрещенный контент).
  * Разрешение спорных ситуаций между пользователями по поводу бронирования.
  * Ограниченный доступ к панели управления контентом без права изменения системных настроек или ролей пользователей.
* **Уровень системы:** Серверный middleware валидации контента и модерации записей.

### 3. Обычный пользователь (User)
* **Назначение:** Размещение объявлений об обмене книг, поиск литературы, бронирование и взаимодействие с каталогом.
* **Права:**
  * Регистрация, авторизация и управление личным профилем.
  * Публикация, редактирование и удаление собственных объявлений о книгах/манге (включая загрузку обложек).
  * Поиск, фильтрация по жанрам, отправка запросов на бронирование и публикация отзывов.
* **Уровень системы:** Клиентский уровень с доступом к защищенным REST API эндпоинтам Node.js (через персональный токен авторизации).
