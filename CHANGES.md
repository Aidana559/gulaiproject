# Что изменено: статусы книг, уведомления, жанры

## Модерация и уведомления
- `lib/moderation.ts` (новый) — скрытие / повторная публикация / удаление / восстановление / одобрение, журнал `data/moderation-log.json`, автовосстановление по сроку, данные для карточки книги.
- `lib/moderation-shared.ts` (новый) — типы, подписи, форматирование дат (используется и на клиенте).
- `lib/notifications.ts` — уведомление хранит запись о действии (`moderation`); уведомления о модерации не обрезаются лимитом 50. Дубли исключены (ключ = id записи журнала; одинаковое повторное скрытие игнорируется).
- `app/api/books/[id]` — PATCH: `hidden`, `reason`, `hideDays`/`hiddenUntil`, `restore`, `reviewed`; DELETE с `reason`. Причина обязательна для скрытия/удаления администрацией.
- `app/api/books/[id]/moderation` (новый) — информация о книге: автор — только свои, администрация — любые.
- `app/api/moderation-log` (новый) — журнал для администрации.
- `app/api/books` — `mine=1`, `state=`, повторяемый `genre=`; `app/api/notifications` — `?all=1`.
- Мягкое удаление (`deleted`) сохранено; при удалении администрацией отзывы и жалобы остаются, чтобы можно было восстановить. Удаление автором — как раньше (с каскадом).
- Автовосстановление: срок учитывается при каждом чтении, плюс фоновая проверка раз в минуту (`instrumentation.ts`) и при запросах каталога/уведомлений. Удалённая книга не восстанавливается.

## Жанры
- У книги `genres[]` (связь «многие ко многим» в рамках JSON-хранилища), повторы без учёта регистра отсекаются (`normalizeGenres`), `genre` = первый жанр.
- `GenreMultiSelect` в формах добавления и редактирования; поиск `q` ищет и по жанрам; в каталоге жанры выбираются несколько (показываются книги со всеми выбранными).

## Интерфейс
- `/book/[id]/info` — информация и история (автор / администрация), кнопки действий для администрации.
- `/notifications` — полная история уведомлений; ссылка в колокольчике.
- Панели: «Объявления» (вкладки, диалог причины и срока, восстановление), «Журнал действий».
- «Мои объявления» теперь показаны в профиле со статусами и причинами.
